任务 ID：SR-05

本次唯一用户流程：已保存“显示/隐藏窗口”或系统代理动作热键后打开「设置/全局热键」窗口，点录制并按下已注册组合；此时该组合只被录制器捕获，不再触发窗口/代理动作。取消（Esc/「取消」/点遮罩关闭）恢复打开前的注册；保存后按新组合重新注册并可由共享入口真实 dispatch。

输入、输出、错误、取消、权限、持久化及生效语义：
- 输入：窗口打开前的现网注册集合（`HotkeyController.state.bindings`，由启动时 `desktop_integration.dart:91-92` 装载）；录制用 `HotkeyKeyCodec` 将 Flutter Key 事件写入 WPF `KeyCode`+modifier。
- 输出：窗口打开 → `beginEdit()` 调 `registrar.unregisterAll()` 丢弃现网注册（等价 `IsPause=true`）；取消/关闭 → `cancelEdit()` 用原 `state.bindings` `registerAll()` 恢复；保存 → 写入 `GlobalHotkeys` 后按草稿 `registerAll()`。
- 错误：`unregisterAll`/注册异常被如实记录为冲突文案，不伪造成功；窗口在注册失败时保持打开（见 SR-06）。
- 取消：Esc/「取消」按钮/遮罩关闭经 `dispose` 走 `cancelEdit()` 恢复旧注册；已保存路径置 `_saved` 防止误恢复。
- 权限：仅本机 UI + FRB/Rust/SQLite；不注册真实 OS 热键、不写系统代理/TUN。
- 持久化：`guiNConfig.json` 的 `GlobalHotkeys[]`（`KeyEventItem` 形状）。
- 生效：保存后立即重注册并经 `DesktopIntegration._onHotkey`（`desktop_integration.dart:297`）分发到与托盘/状态栏相同的入口。
