# T15a 证据 —— 运行观察接线（统计 / 日志 / Clash 代理与连接 / 状态栏 / 菜单）

本回合为 T15a 实施子代理（deepseek-v4.1-flash），目标：把 `crates/core_adapters`
的统计 / 日志 / Clash 原语接入应用层、FRB 桥与 Flutter 观察界面。
**不实现测速（T15b）、不 TUN、不改系统代理、不占用 10808、不 commit。**

## 1. 改动文件与接线点

### Rust：application

- `crates/application/src/monitor.rs`（新增）
  - `StatsService`：按快照差分累加代理/直连字节（u64，节流不丢累计）；代次变化清零会话基线、
    保留节点累计；跨日把 `Today` 归零、`Total` 结转；按活动节点 `IndexId` 记 `TrafficStats`；
    `flush_store` / `clear_all` / `clear_node`。
  - `LogService`：`RingBuffer`（默认 10,000 行 / 10MiB，先到为准）+ 受保护控制队列；级别/关键字
    过滤；采集暂停与滚动暂停分离；`dropped_lines`/`dropped_bytes`/`truncated_lines` 可见；
    消费 `log_batch` / `log_line` 事件。
  - `ClashApiService`：proxies / select / 单节点延迟 / 整组延迟（provider 走 healthcheck）/
    connections / 关闭单个/全部；`supported(Mihomo|SingBox)`，其余“不适用”。
  - `TrafficStore` trait + `InMemoryTrafficStore`。
- `crates/application/src/store_repo.rs`：新增 `SqliteTrafficStore`（`ServerStatItem` 落库，
  按 `IndexId` upsert / delete / clear）。
- `crates/application/src/lib.rs`、`Cargo.toml`：注册模块、加 `core_adapters` 依赖。

### Rust：core_adapters（纯增量）

- `crates/core_adapters/src/clash_api.rs`：新增 `ClashApiClient::select_proxy`
  （`PUT /proxies/{group}`）。既有读逻辑与既有测试未改动。

### Rust：bridge_api

- `crates/bridge_api/src/api/monitor.rs`（新增）：进程级 `MonitorHub`；
  - 快照/控制：`monitor_configure`、`monitor_set_active_node`、`stats_snapshot`、`clear_stats`、
    `monitor_enabled`、`clash_supported`、`set_page_visible`。
  - 流：`subscribe_traffic`、`subscribe_logs`（先回放头部，事件带 `epoch`/`seq`）。
  - 日志：`get_logs`、`clear_logs`、`set_log_filter`、`set_log_pause`、`log_total`。
  - Clash：`clash_proxies`、`select_clash_proxy`、`clash_proxy_delay`、`clash_group_delay`、
    `clash_connections`、`close_clash_connection`、`close_all_clash_connections`。
  - 轮询：`monitor_start_polling`（Xray `/debug/vars`、sing-box `/traffic`，1Hz，显式开启）。
  - `ingest_runtime_event` 接入 engine 的单一事件 sink。
- `crates/bridge_api/src/api/engine.rs`：事件 sink 先喂日志管线再广播。
- `crates/bridge_api/src/api/mod.rs`、`Cargo.toml`：注册、加 `core_adapters`/`tokio`。

### Rust：net_host（最小日志事件转发）

- `services/net_host/src/events.rs`：`EventBus` 变为可克隆（epoch/seq 用 `Arc<AtomicU64>` 共享）。
- `services/net_host/src/session.rs`：stderr/stdout 读取器在写日志文件的同时发 `log_line` 事件。

### Flutter

- `lib/features/monitor/monitor_bridge.dart`：`MonitorBridge` seam + `FrbMonitorBridge` + provider。
- `lib/features/monitor/monitor_controller.dart`：Riverpod 读模型（流量/日志/代理/连接/过滤/暂停）。
- `lib/features/monitor/monitor_format.dart`：字节/速率格式化（无数据显示 `--`）。
- `lib/features/monitor/logs_view.dart`（信息 Tab）：真实日志流、级别/关键字过滤、自动刷新、
  暂停采集、溢出/截断提示；清空按上游 `ClearMsg` 已注释（FND-004）禁用并说明。
- `lib/features/monitor/proxies_view.dart`（当前代理）：代理组卡片/节点、单节点/整组延迟、
  选中切换、排序、自动刷新；非 mihomo 显示“当前内核不提供 Clash API”。
- `lib/features/monitor/connections_view.dart`（当前连接）：Host/Chain/Network/Type/ProcessPath/
  Elapsed 列、过滤、关闭选中/全部、自动刷新。
- `lib/app/shell/side_tabs.dart`：信息/当前代理/当前连接接入上述视图（LAY-MAIN-001/002/003）。
- `lib/app/shell/status_bar_view.dart`：代理/直连实时速率与今日流量取自真实统计（无数据 `--`）。
- `lib/app/shell/main_shell.dart`：`ACT-MAIN-030` 清除所有服务统计真实生效；证据钩子
  `V2RAYN_R_MONITOR_XRAY_PORT` / `V2RAYN_R_OPEN_TAB` / `V2RAYN_R_AUTO_SMOKE`。
