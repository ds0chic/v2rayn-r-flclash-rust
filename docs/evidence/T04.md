## 4. 未知字段保留策略

- **上游数据库**：`SELECT *` 按列名映射；每行完整 JSON 存入 `raw_records`（审计/回放）。
  未知列不进入类型化实体时也不丢失（`raw_records` + 实体 `extra`）。
- **ProtoExtra/TransportExtra**：以 PascalCase JSON 文本列原样存储；已知键类型化，
  其余键 `#[serde(flatten)] extra` 原样保留，`None` 不写、未知键照写。
- **guiNConfig.json**：保留原始 JSON 树写入 `app_meta.upstream_config`；`ConfigStorage`
  `#[serde(flatten)]` 保留全部未知 ConfigItem/根键；`FieldState` 区分缺省/null/空串。
- **RuleSet**：以 JSON 文本列保存，顺序不变；解析/序列化往返不重排。
