## 1. 缺口与做法

缺口（FLD-CFG-117/118/119 一致口径）：canonical `UiItem.MainColumnItem`
持久化了，但正式表格只读 `column_layout` UI 缓存，本轮前无 UI 消费者。

做法（`apps/desktop/lib/features/profiles/**` 内，最小接线）：
- 新增 `main_column_layout.dart`（纯函数，无桥接）：
  `parseMainColumnItems`（未知列保留；空名/坏类型行拒绝）、
  `applyMainColumnLayout`（按 Index 稳定排序、首行胜出；Width<0 隐藏并保留
  默认宽；Width 0 回落默认宽；正宽钳制 40..600；未知列不上表；缺失已知列按
  默认槽位追加）、`encodeMainColumnItems`（可见列截断取整即上游 `(int)`
  语义，隐藏列 -1 哨兵，Index=显示位；未知行原文重写于末尾，不丢）、
  `mainColumnForcedHidden`（`to*` 随 `GuiItem.EnableStatistics`，
  `IpInfo` 随 `SpeedTestItem.IPAPIUrl` + `UiItem.HideColumnIpInfo`）。
  语义来源：冻结 `7d6a967` `ProfilesView.xaml.cs:RestoreUI/StorageUI`
 （只读核对，未改 `work/`）。
- `profiles_controller.dart`：`build()` 经 `_resolveInitialColumns` 优先用
  canonical（非空才生效），否则沿用 UI 缓存/legacy/默认；新增公开
  `resyncColumnsFromCanonical()`（外部 `UiItem` 组保存后重应用，无
  canonical/不可读则 false 且表不动）；`_persistColumns` 经
  `saveSettingsGroup('UiItem', 全组 JSON, UiItem revision)` 写透 canonical
  （成功后重应用 canonical 归一，失败记 `column-save-failed` 事件并保留
  乐观状态）；`column_layout` 节仍作 live-state 镜像最后写入（legacy/
  无桥路径保留）。
- `column_settings_dialog.dart`：仅改文件头注释（canonical 主、ui_state
  镜像）；窗内文案与 key 未动。
- 未动：`crates/**`、FRB/桥文件、ledger CSV、FLD 文档、manifest、他卡文件。
