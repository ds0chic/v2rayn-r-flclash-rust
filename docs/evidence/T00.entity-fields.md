## 4. 迁移路径细节（版本识别 → 转换 → 写回）

### 4.1 `MigrateProfileExtraGroupV2ToV3`（AppManager.cs:575-641）
- 版本识别：`SELECT * FROM ProfileItem WHERE ConfigVersion < 3 AND ConfigType IN (101 PolicyGroup, 102 ProxyChain)`（:580）。
- 转换：按 `IndexId` 从 `ProfileGroupItem` 表取组配置，写 `ProtocolExtra`：`GroupType = nameof(item.ConfigType)`，并复制 `ChildItems/SubChildItems/Filter/MultipleLoad`（:599-609）。

- 失败：单条 `try/catch` 记日志（:617-620）；整批更新失败记日志并返回 false（:631-635）。组表不清理。

### 4.2 `MigrateProfileExtraV2ToV3` + `...Sub`（AppManager.cs:337-362, 477-573）
- 版本识别：分页 `WHERE ConfigVersion < 3 AND ConfigType NOT IN (101,102) LIMIT 100 OFFSET n`（:344-347）。
- 转换（按协议，:486-540）：
  - Shadowsocks：`Security → SsMethod`
  - VMess：`AlterId → AlterId(string)`、`Security → VmessSecurity`
  - VLESS：`Flow → Flow`、`Security → VlessEncryption`
  - Hysteria2：`Path → SalamanderPass`、`Ports → Ports`，并从全局 `_config.HysteriaItem` 取 UpMbps/DownMbps/HopInterval
  - TUIC：`HeaderType → CongestionControl`；`Username = Id`、`Id = Security`、`Password = Security`
  - HTTP/SOCKS：`Username = Security`
  - WireGuard：`PublicKey/RequestHost/Path/ShortId → WgPublicKey/WgInterfaceAddress/WgReserved/WgMtu`（MTU 解析失败默认 1280）
  - 收尾统一 `item.Password = item.Id`（:544），`ConfigVersion = 3`（:546）。
- 写回：`UpdateAllAsync`，返回更新条数（:560）。
- 幂等/失败：`offset += batch.Count - batchSuccessCount`，仅对未成功项重试（:358）；更新异常返回 0（:565-566）。

### 4.3 `MigrateProfileTransportV3ToV4`（AppManager.cs:364-475）

## 7. 关键结论（5 条）

1. 持久化以 `guiNDB.db` 单一 sqlite 数据库承载全部实体；`ProtocolExtraItem`/`TransportExtraItem`/`RulesItem` 不是独立表，而是分别内嵌在 `ProfileItem.ProtoExtra`、`ProfileItem.TransportExtra`、`RoutingItem.RuleSet` 的 JSON 文本中。
2. 版本迁移是显式、可重入的状态机：`ConfigVersion <3` 做协议字段（ProtoExtra）迁移，`=3` 做传输字段（TransportExtra）迁移，`=4` 为当前；每步以版本阈值过滤并在成功后回写，失败项保留旧版本以便下次重试。
3. `ProfileItem` 有 9 个 `[Obsolete]` 旧列（HeaderType/RequestHost/Path/Extra/Ports/AlterId/Flow/Id/Security）仍留在表中，但只被迁移代码读取、不再被表单或生成器读取；新代码统一走 `ProtoExtra`/`TransportExtra`。
4. 跨实体引用有两类键：按字符串名（Remarks）解析的路由 OutboundTag 与订阅 Prev/Next Profile，以及按 IndexId 列表解析的组 ChildItems / 按订阅 Id + 正则解析的 SubChildItems；全部在生成配置时解析，失效均降级为告警并回退，不会中断生成。
5. `ProfileGroupItem` 为过时表，仅在 V2→V3 迁移中被读取，迁移后未删除；`RoutingItem.Locked` 是仅用于识别并删除遗留锁定项的 `obsolete_candidate`。
