## 3) 真实校验统计（`target/t10/matrix/results.json`）

- 内核：`tools/cores/xray/v26.3.27/xray.exe`（`run -test`）、
  `tools/cores/singbox/v1.14.2/sing-box.exe`（`check`）；单用例等待 ≤60s，
  只 kill 自有子进程；端口逐用例探测空闲（基址 11808 递增，从不触碰 10808，
  生成物断言不含 `10808`）。
- **16/16 PASS**：xray/sing-box 各 8 用例——PolicyGroup 五模式
  （LeastPing/Fallback/Random/RoundRobin/LeastLoad）各一次、ProxyChain、
  Custom 透传（由基线 VLESS 配置生成后回灌）、模板注入
  （AddProxyOnly=true + ProxyDetour 指向合并后真实 tag：xray `det1`、
  sing-box `corp-detour`）。
- mihomo：`t10_mihomo_mixin_file_round_trip`（合并键断言 + 临时文件写读往返，
  未执行内核）。
- 过程发现并修正的真实问题：VLESS 缺 `encryption:none` 致 xray exit 23；
  全局启用模板把 `detour` 注入 sing-box selector/urltest 致 check 失败——
  矩阵改为模板用例单 build 隔离（D10-4）。
