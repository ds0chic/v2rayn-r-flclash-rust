## 1. 导入根因与修复

**根因（真实桥缺陷）**：`crates/bridge_api/src/api/subs.rs::import_from_text`
只在 `subid` 非空时调用 `replace_sub_profiles` 落库；从剪贴板导入不带 `subid`，
因此真实桥返回 `ok=true, imported=N`，但 SQLite 一行都没写。Dart 侧随后
`reload()` 读回 0 行，界面状态消息却提示“已导入 N 个节点”——即用户看到的
“点了没法导入”。

复现（真实 `bridge_api.dll` + 真实 SQLite，修复前）：
```
apps/desktop/test/t21e_import_real_bridge_test.dart
  import ok=true imported=4 errors=0
  profiles before=0 after=0        # 未落库
```

**Dart 侧修复**（保持 `crates/**` 不变，见决策文档）：新增
`lib/features/subs/import_persistence.dart::persistImportedProfiles`。当
`importFromText` 返回解析出的 `profiles` 且未绑定订阅时，UI 通过既有
`BridgePort.saveProfile` 逐条落库（每次重新读取 `profileRevision()`，维持乐观
revision 契约）。`subs_actions.dart` 的 `importFromClipboard` /
`importFromTextDialog` 都走该路径，再 `reload()`。

修复后（同一真实桥测试）：
```
persisted.saved=4 failed=0 ; profiles before=0 after=4
```

**错误 UX**：`describeImportFailure` 输出「第 N 项 + 原因分类 + 错误码」，
分类覆盖空内容 / 未识别格式 / 超限 / Base64 解码失败；空剪贴板提示保留。

## 3. 订阅 URL 引导行为

剪贴板为 `http(s)://…` 且 `importFromText` 未解析出分享链接时，弹出
`sub-url-import-dialog`（key `sub-url-import-add`「作为订阅添加」）。确认后调用
既有 `SubsController.save` + `update()`（即 F-SUB-003 下载管线），随后
`reload()` 节点表。

真机用例使用本地 loopback HTTP（端口 11821，`_bindLoopback()` 依次 11821..11831，
绝不含 10808）返回合成 Base64 列表；集成测试断言：
- loopback 服务器确实被请求（`hit`）；
- 弹窗出现并可点击；
- 下载节点的备注 `sub-one` / `sub-two` 出现在节点表。
真实 Rust `subscriptions::download` 已设 `no_proxy()`（无显式代理时不读环境代理）。

## 6. Rust 侧最小补丁建议（本轮未改 crates）

`crates/bridge_api/src/api/subs.rs::import_from_text` 在无 `subid` 时也应落库。

复现输入：
```
vless://11111111-1111-1111-1111-111111111111@a.example:443?encryption=none#one
```
期望：`ok=true, imported=1` 且 `query_profiles` 可见该行；当前：`query_profiles`
`total` 不变。

最小补丁（示意）：
```rust
let sub = subid.filter(|s| !s.is_empty());
match sub {
    Some(sub) => {
        engine().replace_sub_profiles(&sub, profiles.clone(), false)?;
    }
    None => {
        // 批量落库；revision 由引擎自增，避免每条外部读取。
        for profile in profiles.iter().cloned() {
            let rev = engine().desired_revision();
            engine().save_profile(profile, DesiredRevision::new(rev))?;
        }
    }
}
```
更优：在 `application::AppEngine` 增加 `insert_imported(profiles) -> Result<usize>`
原子批量写入，并让 Dart 侧删除 `persistImportedProfiles` 兼容层。
