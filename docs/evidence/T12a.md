# T12a 证据 — 设置契约与存储全量 + 设置界面 + 立即生效接线

范围：`guiNConfig.json` 全量 `AppSettings`（180 字段）、`AppEngine::load_settings/save_settings/save_settings_group`、
FRB 设置 DTO 与菜单/窗口接线、Flutter 选项/主题/热键窗口与 `immediate` 项落地。
系统代理/自启/UWP/管理员重启/TUN/内核重载的下层平台行为归 T13，本轮只存储并在 UI 标注“未接线”。

## 1. 改动文件与接线点

Rust
- `crates/domain/src/settings.rs` — 全量 `AppSettings` 重写：PascalCase 键（含 `IPv4Address`/`FakeIP` 等上游缩写）、枚举整数、`#[serde(flatten)]` 未知键保留、`Option<String>` 区分 null/空串、逐字段默认（属性初始化器）+ `apply_load_defaults`（LoadConfig 层）、`classified_changes`（apply_timing 分类）、`CoreTypeItem` 初始化。
- `crates/domain/src/settings_timing.rs` — 由 `compat/fields.settings.yaml` 生成的 180 条 `FIELD_TIMING` 表（`classify_leaf`/`classify_group`）。
- `crates/domain/src/entities.rs` — `InboundListener/GlobalHotkey/ColumnDefinition/WindowState/CoreTypeBinding` 的 PascalCase 序列化与字段默认（`AllowLANConn`/`NewPort4LAN`/`EGlobalHotkey`）。
- `crates/domain/src/enums.rs` — `GirdOrientation`/`SysProxyType`/`ConfigType` 整数 serde 与 `Default`。
- `crates/application/src/settings.rs` — `SettingsState`、`validate_settings`、`apply_group_patch`、`SaveSettingsOutcome`（restart_core/restart_app/next_launch 集合）。
- `crates/application/src/engine.rs` — `settings` 状态、`load_settings`、`save_settings`（整树 revision）、`save_settings_group`（组 revision）、`persist_config` 原子合并写、`read_settings_state`（剥离引擎 meta 键）。
- `crates/bridge_api/src/api/settings.rs` + `frb_generated.rs` — 25 组强类型 DTO、`get_settings`/`save_settings`/`save_settings_group`/`save_settings_json`/`settings_revision`；结果返回 `apply_timing` 分类与重启集合。

Flutter（`apps/desktop/lib`）
- `features/settings/settings_defaults.dart` — 与 `AppSettings::default()` 对齐的默认文档（synthetic 桥/回退用）。
- `features/settings/settings_controller.dart` — 文档加载/整树保存/分组保存、revision、`apply_timing` 状态提示、`immediate` 生效派发。
- `features/settings/settings_fields.dart` — 复选/文本/数字/下拉/分组/未接线提示控件。
- `features/settings/option_setting_window.dart` — 12 个 Tab：核心基础/显示/系统代理/Tun模式/内核类型/测速/Fragment/多路复用/KCP(注明)/HappyEyeballs(FakeIP 联动)/TUN高级/ClashUI。
- `features/settings/theme_setting_dialog.dart` — 主题/强调色/字体族/字号/语言，改动即时应用并经 `save_settings_group('UiItem')` 持久化。
- `features/settings/global_hotkey_window.dart` — `EGlobalHotkey` 5 行录制（修饰键+键码）与保存；OS 注册标注留 T13。
- `features/settings/settings_actions.dart` + `app/menu/main_menu.dart` + `app/shell/main_shell.dart` — 菜单接线（ACT-MAIN-024/028、UI-THEME-WINDOW、主题设置；025/026/029/030/031、ACT-WIN-004 标注未接入）。
- `app/shell/ui_shell_controller.dart` + `shared/theme/app_theme.dart` + `app/app.dart` — 主题/强调色/字体/字号/语言/布局/隐藏IP/统计等 `immediate` 项立即生效。
