## 5. 异步与取消矩阵

| 动作类 | job | cancellable | 取消入口 | 取消后行为 |
|---|---|---|---|---|
| 测速（TCPing/真连接/UDP/测速/混合/快速） | true | true | Esc（节点表聚焦） | SpeedtestService.ExitLoop 取消所有 CTS，提示 SpeedtestingStop，已测得结果保存 |
| 订阅更新 | true | false | 无显式入口 | SubscriptionHandler.UpdateProcess 无 token，无法中途取消 |
| 导出内部链接 | true | false | 无 | Task.Run 同步完成 |
| 备份/恢复 | true | false | 无 | 完成后重启或写 OperationMsg |
| 检查更新 | true | false | 无显式入口 | 逐项进行到完成 |
| 策略组预览 | true | false | 无 | 切换页签触发 |
| Clash 代理/连接轮询 | true | true | 视图释放 | CancellationDisposable，捕获 OperationCanceledException |
| Reload 内核 | true | false | 无（重入排队） | `_hasNextReloadJob` 标记，执行完再跑一次 |

## 6. unresolved 清单

1. **全局热键默认键**（ACT-HOTKEY-001）：冻结源码中 `GlobalHotkeys` 默认仅空集合，任务给定的“显示窗口/清除代理/设置代理/不改变代理/PAC 默认键”在源码中不存在，无法核实；Windows 与非 Windows 默认差异亦无依据。
2. **热键平台差异**（ACT-HOTKEY-006）：WPF 在 `IsPause=true` 时把热键转为普通 KeyDown 转发给焦点元素；Avalonia 直接 return，不转发；行为差异未带注释说明。
3. **热键重载**（ACT-HOTKEY-006）：WPF 提供 `HotkeyManager.ReLoad()`，但保存热键后是否调用 `ReLoad` 在源码中未见路径，无法核实。
4. **连接关闭按钮**（ACT-CLASH-006）：`ClashConnectionsView.xaml.cs:63` 定义了 `btnClose_Click`，但构造函数与 `ClashConnectionsView.xaml` 均未发现对应 `Click=` 绑定，是否为可达路径无法核实。
5. **拖动多选语义**（ACT-PROF-033）：WPF 拖放起点使用 `lstProfiles.SelectedIndex`（单值），落点使用目标行，未处理多选整体拖动；多选拖动语义未在源码中明确定义。
6. **订阅更新取消**（ACT-MAIN-020/021/022/023、ACT-SUB-006、ACT-TRAY-010/011）：`SubscriptionHandler.UpdateProcess` 无 CancellationToken，源码未提供取消入口，取消行为按“不可取消”记录而非默认。
