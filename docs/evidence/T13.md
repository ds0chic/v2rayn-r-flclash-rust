# T13 证据 —— 系统代理四态/PAC、托盘、热键、自启、UWP、管理员重启接线与退出恢复

本回合为 T13 接线子回合（deepseek-v4.1-flash）。目标：把 T13 平台原语
（`crates/platform`）编排为应用层服务、桥接到 Flutter、并把状态栏/托盘/热键/自启/退出恢复接上线。
**自动化测试全程不修改宿主系统代理 / WinINET / 注册表 Run 键；真实后端只编译，仅在用户手动操作时生效。**

## 1. 交付与接线点

### Rust

- `crates/application/src/platform_service.rs`（新）：`PlatformService` 编排
  - 四态应用/清除/不变/PAC、应用前快照、逐字段所有权账本、退出恢复（只恢复仍属本应用的字段，
    用户改过的保留并报告冲突）、PAC 生命周期（幂等）。
  - 14 个单元测试（fake 后端）。
