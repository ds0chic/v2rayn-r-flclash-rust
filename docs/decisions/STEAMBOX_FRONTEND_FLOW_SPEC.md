**SteamBox四模块：固定前端元素行为与完整使用流程**

本规格补充只读的`outputs/STEAMBOX_FLUTTER_RUST_PLAN.md`，配合`FRONTEND_INTERACTION_CONTRACT_2026-10-02.md`、`STEAMBOX_FRONTEND_FIELD_POLICIES.md`、`steambox-frontend-elements-2026-10-02.csv`及本轮流程研究使用。目标仍为Flutter前端+Rust后端，只写实施和验收规格。应用实现、真实UI操作和性能验证：未运行。

**1. 用户看到的产品固定为四项**

导航按截图保留网络加速、账号切换、库存游戏、卡片图标挂卡，顺序、窄侧栏、页面密度和已有页内tabs保持。公共设置、原启动Home fallback、标题栏、托盘和必要弹窗属于支撑，不增加新的主功能入口。Authenticator/ASF/GameTools不显示、不加载、不初始化、不迁移专属数据。

本文规定新实现要达到的行为。静态发现的原版缺陷不能为了“保持原版”复刻：重复提交、身份不符继续挂卡、保存失败引导重置、伪倒计时、取消却写文件，均明确修正。样式更漂亮不作为流程通过证据。

**2. 元素台账与规则合成方法**

本轮从五个源码views根的AXAML解析了2684个声明节点：网络907、账号215、库存612、挂卡257、公共壳/设置693。这里包括布局、属性、模板和非当前入口页面，数量不是2684个实际按钮。XML注释未作为元素处理。每个节点有稳定selector-derived ID、源路径/行号、类型、命令/参数、事件、绑定、可见/启用条件及P00–P25规则。

其中2295个节点属于保留源码视图；246个来自明确非当前入口或调试视图，标not_applicable；143个公共候选节点仍需对照路由/条件确认，标identified。以上仅源码覆盖，不能代替运行时可达性。候选不自动加回产品，也不能默默删行提高覆盖率。

有效行为 = 本文页面action表 + 字段提交策略 + 公共P规则 + 权威状态/冲突表。source绑定只能帮助定位，不能让执行模型自行猜效果。属性/样式节点不发业务命令，显示节点只读投影，动态菜单从四模块action注册表生成；模板每个实例补稳定account/AppId/script ID，不使用数组index作业务目标。

AXAML之外的窗口按钮、codebehind注册事件、动态托盘、权限弹窗、文件picker、二维码/原生接口子窗口须在实施时追加元素ID；不得称XML覆盖意味着所有运行时元素已verified。账号卡的额外DoubleTapped handler就是必须跨源合并的例子。所有生产元素必须有路由和规则；未解析action、P00承载点击或未校验候选路由均阻止该流程放行。

**3. 整体上下文与冲突关系**

| 用户动作 | 冲突域和固定处理 | 不冲突的操作仍可用 |
|---|---|---|
| 社区加速启停/重新应用 | 单网络owner，desired→applied串行；相同目标去重，当前阶段可见；状态经真实listener/接入确认 | 切页、搜索库、查看账号、读设置、正常滚动 |
| 脚本/规则修改 | 保存目标revision；按字段表标下次启动代理生效，运行snapshot保持旧applied；下一启动一次取完整新snapshot，不偷偷重启 | 查看日志、页面切换、其他未冲突字段编辑 |
| Steam账号切换 | 全局Steam/account epoch排他；停止本任务依赖AFK/挂卡/Cloud/成就操作后再切；实际SID确认前不宣告新账号已登录 | 社区反代与不依赖Steam身份的设置/导航 |
| Cloud/成就/编辑落Steam | 锁目标SID+AppId+资源版本；账号切换前等待/取消可取消阶段；不可逆已提交结果先核实 | 非目标只读库、导航、无身份关联网络任务 |
| GameList AFK和挂卡 | per-AppId worker所有权/引用计数；两任务共享需显式协议；互斥时给具体原因，停止一个不误停另一个 | 查看详情、队列重排允许部分、其他页面 |
| 下载完成电源计划 | 一个可取消计划，锁实际选中监控任务集合与完整快照；账号/监控目标变化取消旧计划 | 滚动、切页、取消计划及正常读操作 |
| SDK加速 | SDK operation按game/area串行；变区服按厂商真实状态处理，超时重查，不创建第二次加速 | 社区HTTP能力与其他页面，除已证明冲突 |
| 主窗隐藏/关闭/退出 | Tray=true主窗X隐藏任务继续；Tray=false主窗X真正退出清理；托盘退出始终真实退出 | 隐藏后第二实例唤回同一状态，无重复worker |

本轮不在宿主停止Steam或其他客户端。将来切账号真实验收需要明确隔离测试环境授权；普通CI只停本项目拥有的测试进程。网络系统接入不改宿主代理、不碰10808。

**4. 网络加速每类元素的确定逻辑**

| action/元素 | 固定逻辑与可见反馈 | 失败、焦点、恢复 |
|---|---|---|
| StartProxyCommand | 启动前校验配置/端口/证书，listener ready后提交系统接入；按钮“正在启动”，完成才变“停止”；停止先撤接入再停listener | 权限取消/撤接入失败有持久状态；不闪成已启动/已停止；页面保持，焦点留按钮 |
| 加速模式选择 | 保留原版运行中禁用模式选择；禁用原因“请先停止加速再切换模式”；停止确认后才可改，保存选择于下次启动应用 | 不发明运行中热切换；新模式启动失败说明接入恢复结果，不能显示新值已生效 |
| 服务域名/ThreeStateEnable/单服务开关 | 明确全选范围是当前可选服务，不包括无能力项；部分选中mixed；保存规则revision，运行中显示下次启动生效，不触发restart | 刷新保留选择；删除规则后不引用旧index；网络不可用不清空用户选择 |
| RefreshCommand | 只刷新规则/状态来源，不反向开关加速；保留最后数据和服务选择 | 离线提示刷新失败，原有效数据仍显示 |
| ProxySettingsCommand | 原设置页/弹窗位置，带当前snapshot；按字段策略保存，显示“已保存，下次启动加速生效”，不加全局Apply按钮 | 输入错误就地标，不丢草稿；关闭恢复启动按钮焦点 |
| Setup/Delete/Show/OpenCertificate* | 查看/导出公有证书与安装信任分别执行；移除信任前处理相关运行会话，只删除owned fingerprint | 原系统拒绝不伪成功；目录打开仅交付OS；秘密不可见于日志 |
| Edit/Reset/OpenHosts* | 编辑与重置有明确目标范围，typed helper只改owned段；重置不会清掉其他软件条目 | 并发冲突说明；不因打开编辑器就显示已保存 |
| OpenLogFileCommand/代理日志 | 打开日志保持脱敏；页内日志有界增量，用户滚离底部不强行滚回 | 日志失败不改变网络运行状态；可恢复路径清楚 |
| 图表/服务状态/瞬时累计值 | 同一runtime epoch读投影；图表2–5Hz合并，隐藏停止绘图而代理继续 | 断连显示上次可靠值及时间，累计归零需源定义事件 |
| NATCheck/DNSCheck/IPv6Check/ConnectTest | 冻结本次测试输入；按钮和codebehind共用一个请求，进行时同类single-flight；结果注明测试目标 | 改输入取消旧查询或结果不回写；检测失败不自动停代理，不假报“全网络不可用” |
| DNS/DoH两个输入 | UseDoh决定可编辑项；切换不清掉另一方案保存值；IP/URL就地校验，认证链失败正常报错 | 不反复强制焦点；检查只读，不自动修改系统DNS |
| AddNewScript/EditScriptItem/DeleteScriptItem | 导入保留文件picker；编辑保留外部文本编辑器+原确认入口，编辑暂存副本，确认才原子提交，取消丢副本；删除仅目标script ID，原需要时确认 | 不发明内嵌编辑器或额外保存窗；提交失败保留可恢复副本且原版本可用；目标消失不覆盖别项 |
| Download/RefreshScript/RefreshALL | 每项operation、有效进度；同ID去重，全刷新有界并发；商店返回不重复下载 | 网络错保持已安装版本，不将残缺脚本标启用；来源链接只打开外部网页 |
| 脚本启用/排序/自动更新/仅Steam浏览器 | 原值存储+对应字段时机；规则/启用/注入次序下次启动代理生效；自动检查在下一自动检查触发读开关，手动更新独立 | 当前运行旧applied与待生效值区分；保存失败按revision恢复；灰掉说明依赖，不禁用整页 |
| SDK Install/Uninstall/选择安装路径 | picker取消零副作用，明确安装路径与厂商真实步骤；卸载先确认影响并处理自有会话 | 失败保留已知状态与继续/重试，不弹无限路径对话框 |
| GameAccelerator/ImmediatelyAccelerate/区服变更 | game ID+area稳定目标，合法权益检查；显示SDK确认状态，变区服一次操作 | 回调乱序按epoch/operation拒绝；区服取消保留原选择，超时重查 |
| ConnectTest/GameLaunch/DeleteMyGame/ShowXunYouWindow | 测速和启动游戏独立；删“我的游戏”不卸载游戏；显示厂商窗口不重启加速 | 启动交付与已运行分别显示；路径/SDK不可用就地说明 |

网络默认/输入和TwoLevelAgent用户名密码、端口、OnlyEnableProxyScript等全部适用字段必须按101字段索引逐项分配策略，不能把表格未单列的字段当自由发挥空间。

**5. 账号切换每类元素的确定逻辑**

|---|---|---|

| RefreshCommand | 更新可见账号来源/头像，保持排序策略及有效selection | 完整快照前不删除暂时未返回账号；不toast成功但显示旧身份 |
| 复制昵称/账号/SteamId | 文本编辑焦点优先；菜单复制确切目标；不变账号、不克隆 | 剪贴板失败提示；成功简短反馈一次 |
| 离线模式/Persona菜单 | 修改精确目标的选项与对应源触发时机；不误作用当前另一账号 | account epoch变动时拒绝过期参数；反馈保存与登录效果分别准确 |
| EditRemark/SetAccountAvatar | 单账号draft/picker；取消保留旧值，保存后列表与托盘一致 | 头像解码/写入失败保留原图，大小固定 |

身份变化使旧账号结果不能回写新账号UI投影；已经提交的旧Cloud/成就操作仍按原SID+AppId+operation在journal里结算/核对，不丢弃终态或私自当已取消。界面所有当前用户标签从同一Rust身份投影更新。账号卡“MostRecent”和文件写成功不能作为真实已登录依据。

**8. 公共壳、设置、窗口元素**

根导航同页重复点击不重置任务/滚动，切根清子BackStack而保留轻量view状态。页内tabs同义；返回恢复原过滤/selection/scroll/focus。焦点规则：打开模态落第一可操作字段/原指定按钮；关闭返回触发元素；失效元素返回所在列表，不跳无关导航。Esc只处理最顶层可取消层。

设置长页五锚点不改路由。Theme/Accent/Font/Language/材质/图片等即时预览与存储确认；失败回可靠值；GPU及插件启用标重启要求；Steam启动参数/路径/模式保存后说明下一次启动使用。开机自启等外部效果按实际用户/平台确认，不能只写文件就提示完成。MinimizeOnStartup按手动/silence来源解释，手动启动显示窗口。

101保留字段逐项策略见`STEAMBOX_FRONTEND_FIELD_POLICIES.md`，元素CSV里的field_keys关联精确字段；别名绑定同一字段ID，不能临时决定commit policy。无唯一动作/字段策略的元素先补决策，再实现。缺省、非法值、TwoWay输入、未知值fallback都固定。目录按钮只打开明确路径，不靠7.5秒全局锁阻止正常连点；同目标请求在OS交付期间去重，之后可重试。About信息/许可链接只读，彩蛋不得改变四模块功能或使用时状态。

插件页只四项，disable/safe mode保留原有效语义；不新增删除按钮或恢复隐藏插件。旧默认页指向删模块按原Home/有效页回退。通知只作辅助；关键错误、待应用/需登录/需恢复留在当前目标附近；无任务编号、原始error_key、内部字段命名直接展示。
