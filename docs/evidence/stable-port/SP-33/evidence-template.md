## 通用记录格式（每步一行 JSON）

`{"step":"P0", "entry":"<真实入口>", "expected":"...", "actual":"...",
"exit":0, "evidence":"<截图/日志/文件hash路径>", "cleanup":"owned pid/目录已清"}`

失败判定：任一 `actual != expected` 即停，保留现场（数据目录/日志路径），
记 `blocked` 并登记，不重放非幂等写。取消语义：已提交操作不假称未改变。
`version` 探针只记“工具/核在位识别”，不计入任何链路通过项。

## 必填步骤（对照实例清单 P0–P7 打勾并贴 JSON 行）

- [ ] P0 包身份（zip sha / flat 布局 / 无内核捆绑 / 未武装断言）
- [ ] P1 端口探测（≥11808 空闲；10808 未触碰快照）
- [ ] P2 普通入口首次启动（窗口截图 + `guiNNDB.db` 落点）
- [ ] P3 合成导入（4 节点清单 diff）
- [ ] P4 真实 apply（desired/applied revision + journal + 回环端口探测）
- [ ] P5 托盘/热键/窗口/DPI（截图/录屏路径）
- [ ] P6 更新检查/清理（owned 资源回收确认）
- [ ] P7 备份/重开/恢复（hash + 前后 diff 为空）
