## 2. 布局结构细节

### 2.1 主窗口三态布局
- 枚举 `EGirdOrientation { Horizontal, Vertical, Tab }`（`ServiceLib/Enums/EGirdOrientation.cs:3-8`），默认 `Vertical`（`ConfigItems.cs:93`）。
- WPF 三块 Grid 常驻、按 orientation 切 Visibility（`MainWindow.xaml.cs:364-366`）：
  - `gridMain`（Horizontal）= 3 列 `1* / 10 / 1*`：`tabProfiles`（左）+ `GridSplitter` + `tabMain`（右 TabControl，3 Tab）。
  - `gridMain1`（Vertical）= 3 行 `1* / 10 / 1*`：`tabProfiles1`（上）+ Splitter + `tabMain1`（下，TabStripPlacement=Left）。
  - `gridMain2`（Tab）= 单独 `tabMain2`（4 Tab：Profiles/Msg/Proxies/Connections）。
- Avalonia 结构镜像（`MainWindow.axaml:117-154`），但用 `IsVisible` 而非 `Visibility`，且用 `ClearLayoutContent` + `OneWayBind(...Content)`（`MainWindow.axaml.cs:403-469`）。
- 拆分条实际为固定 10px 轨道，两侧为 Star；因此 `MainGirdHeight1/2` 存的是**两侧面板的 Star 值**（WPF `RestoreUI` `:334-341` / Avalonia `:378-385`）。
- 持久化：`StorageUI` 保存 WindowSize + 两分栏（WPF `:345-357`/Avalonia `:389-401`）；`ConfigHandler.SaveMainGirdHeight:2989-2997` 存 `(int)(v+0.1)`。触发时机：`AppEvents.AppExitRequested`（WPF `:132-136`）。
- `ShowClashUI` 控制 Msg/Proxies/Connections 三个 Tab 的可见性（WPF `:383-385`；Avalonia `:421-423`）。
- 脚本模式（Tab）下 Avalonia 未对 `tabMsgView2` 绑定 ShowClashUI（`:440-446` 只绑定 proxies2/connections2），WPF 也未绑 msgView2（`:422` 仅 proxies2/connections2）——两侧一致。

### 2.2 节点表列
- WPF `MyDGTextColumn` 用 `ExName`（`ProfilesView.xaml:282-373`）；Avalonia `DataGridTextColumn/TemplateColumn` 用 `Tag`（`ProfilesView.axaml:209-318`）。
- 14 列默认顺序与宽度见 `layouts.yaml:LAY-PROFILES-002`。
- 列持久化：`UiItem.MainColumnItem`（`List<ColumnItem>{Name,Width,Index}`，`ConfigItems.cs:104,178-183`）。WPF `RestoreUI:328-365` / `StorageUI:367-387`；Width<0 记为隐藏。`to*` 列受 `GuiItem.EnableStatistics`，`IpInfo` 列受 `SpeedTestItem.IPAPIUrl` 与 `UiItem.HideColumnIpInfo`（`:349-356`）。
- 列宽自适应按钮 `btnAutofitColumnWidth` → `AutofitColumnWidth()`（`ProfilesView.xaml.cs:296-314`）。

### 2.3 连接表列
- 6 列：Host/Chain/Network/Type/ProcessPath/Elapsed（`ClashConnectionsView.xaml:82-111`）。
- 持久化 `ClashUIItem.ConnectionsColumnItem`（`ConfigItems.cs:219`），读写 `ClashConnectionsView.xaml.cs:70-131`。

### 2.4 字体/主题/DPI/布局入口
- 字体族 `cmbcurrentFontFamily`（WPF `OptionSettingWindow.xaml:976`；Avalonia `:745`）；字号/主题/语言在 `ThemeSettingView`。
- 主布局方向 `cmbMainGirdOrientation`（WPF `:1111`；Avalonia `:862`），绑定值 `MainGirdOrientation`（`OptionSettingViewModel.cs:63,196,371`）。
- `EnableHWA` 仅 WPF 有开关（`OptionSettingWindow.xaml:906`）；WPF 主窗口构造按之设置 SoftwareOnly（`MainWindow.xaml.cs:151-154`）。
- WPF 全局渲染样式 `WindowGlobal/ViewGlobal`（`App.xaml:206-230`）：`TextFormattingMode=Display`、`TextRenderingMode=ClearType`、`TextHintingMode=Fixed`、`FontFamily=MaterialDesignFonts.MyFont`。
- WPF 默认色 `BundledTheme Light/Blue/Lime`（`App.xaml:11-15`）；Avalonia `SemiTheme` + `RequestedThemeVariant=Default`（`App.axaml:11,19-24`）。

### 2.5 窗口尺寸持久化
- 通用 `WindowBase<T>`：Loaded 读 `GetWindowSizeItem(GetType().Name)`（WPF `WindowBase.cs:14`；Avalonia `:26`，按 `screen.Scaling` 换算并居中），OnClosed 写回（WPF `:35`；Avalonia `:58`）。
- `ConfigHandler.GetWindowSizeItem:2963-2972`、`SaveWindowSizeItem:2974-2987`；`WindowSizeItem{TypeName,Width,Height}`（`ConfigItems.cs:266-271`）。
- `TypeName = GetType().Name`，与窗口类名一一对应；window_inventory 中的 Window 均走此机制（MainWindow 额外在 StorageUI 保存，`MainWindow.xaml.cs:347`）。
- Avalonia `MessageBoxDialog` 不走 WindowBase（自定义 Window）。

## 4. 截图采集步骤（供 T01 或具备 GUI 环境时执行）

> 本 T00 环境无法运行 WPF/Avalonia GUI，`layouts.yaml` 全部 `screenshots: []`。以下为可执行采集方案。

### 4.1 环境与隔离
1. 使用**干净测试配置**：全新空数据目录，不复用真实 `guiNConfig.json` / `guiNDB.db`。
   - 启动参数或首次运行后立即清空配置；建议导出一次基线配置并备份。
2. **隔离数据目录**：把 v2rayN 数据目录指向临时路径（如 `%TEMP%\v2rayn-shot\` 或 `/tmp/v2rayn-shot`），避免污染。
3. 关闭系统级代理/TUN，避免窗口外副作用。

### 4.2 分辨率 / DPI 组合（每组合各采一轮）
- Windows：1920x1080 @ 100%；1920x1080 @ 125%；2560x1440 @ 150%；1366x768 @ 100%。
- macOS：1440x900 @ 默认；若可调，Retina 2x 与 1x 各一轮。
- Linux：1920x1080 @ 100%（X11 与 Wayland 各一轮，如可行）。

### 4.3 需采集的窗口与布局清单（与 LAY-* 对应）
- 主窗口：Horizontal / Vertical / Tab 三态，各含 Clash 关闭态与开启态（ShowClashUI）。
- 节点视图：默认列、隐藏部分列、列重排后、过滤态、右键菜单展开。
- 消息视图、代理视图、连接视图（含自动刷新开关态）。
- 参数设置：核心 / 显示 / 系统代理 / Tun 模式 / 内核类型 五页；重点对比平台条件项的显示差异（HWA、Hide2Tray、MacDock、PAC 脚本、AutoRun）。
- 主题设置 Flyout / Popup（WPF 与 Avalonia 各一）。
- 各对话框：AddServer / AddServer2 / AddGroupServer / SubSetting / SubEdit / ProfilesSelect / RoutingSetting / RoutingRuleSetting / RoutingRuleDetails / DNSSetting / FullConfigTemplate / GlobalHotkey（Windows）。
- 备份与恢复、检查更新、二维码、选择节点。
- 消息框：Avalonia `MessageBoxDialog` 的 Yes/No 态；WPF 系统 MessageBox。
- 托盘菜单：Windows `TaskbarIcon` 菜单；macOS/Linux `NativeMenu`。
