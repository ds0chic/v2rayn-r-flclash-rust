## 2. `compat/domain-map.yaml` 统计

### 2.1 结构与统计口径

文件顶层 sections：`enums`（序列）、`types`（序列）、`settings`（含 `root` 与 `items`）、
`references`（序列）、`migrations`（序列）、`coverage`（自述数字）。每个 rust 条目下用 `fields:` 给出
字段名 → `{ fld, upstream_key, type }` 映射；`fld: null` 表示"未知扩展保留槽"（对应领域 `extra`）。

统计口径：
- **rust 条目数** = `enums` + `types` + `settings.root`(1) + `settings.items` + `references` + `migrations`。
- **字段映射条目数** = 各 `fields` 下的条目总数（含 `fld: null` 的 `extra`）。
- **覆盖 FLD-\* 唯一 ID** = 所有字段条目的 `fld`（支持 `FLD-ENT-015/016/...` 复合写法与枚举 `ledger`）
  展开后的唯一集合，与 `compat/fields.yaml` 域 `FLD-CFG-001..180` ∪ `FLD-ENT-001..158` 求交。
- **未覆盖清单** = 域内未被任何映射引用的 ID。

### 2.2 统计命令（已运行）

```powershell
python "C:\Users\Colby\AppData\Local\Temp\opencode\dmstats.py"
```

脚本内容（等价可复核；保存为 `dmstats.py` 后运行，路径指向本仓库 `compat/domain-map.yaml`）：

```python
import yaml, re
p = r'C:\Users\Colby\Documents\Codex\2026-10-01\v2rayn-flclash-rust-v2rayn\compat\domain-map.yaml'
d = yaml.safe_load(open(p, encoding='utf-8'))
def flds(fd):
    return [v['fld'] for v in fd.values() if isinstance(v, dict) and 'fld' in v]
def expand(raw):
    if raw is None: return []
    toks = str(raw).split('/')
    pre = re.match(r'(FLD-[A-Z]+-)', toks[0]); pre = pre.group(1) if pre else ''
    return [t if t.startswith('FLD-') else pre + t for t in (x.strip() for x in toks) if t]
types = d['types']; root = d['settings']['root']; items = d['settings']['items']
rows = ([v['fld'] for t in types for v in t.get('fields', {}).values() if isinstance(v, dict) and 'fld' in v]
      + [v['fld'] for i in items  for v in i.get('fields', {}).values() if isinstance(v, dict) and 'fld' in v]
      + [v['fld'] for v in root.get('fields', {}).values() if isinstance(v, dict) and 'fld' in v])
cov = set()
for r in rows: cov.update(expand(r))
for e in d['enums']:
    if e.get('ledger'): cov.update(expand(e['ledger']))
univ = set('FLD-CFG-%03d' % i for i in range(1, 181)) | set('FLD-ENT-%03d' % i for i in range(1, 159))
print('rust_entries', len(d['enums']) + len(types) + 1 + len(items) + len(d['references']) + len(d['migrations']))
print('field_entries', len(rows), 'with_id', sum(1 for r in rows if r is not None),
      'extra_null', sum(1 for r in rows if r is None))
print('covered_unique', len(cov & univ), 'universe', len(univ), 'uncovered', len(univ - cov))
```
