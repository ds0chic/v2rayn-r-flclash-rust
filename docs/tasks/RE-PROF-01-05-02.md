## 输入/输出/错误/取消/权限/持久化/生效语义

- 输入：命令开始时对当前 `ProfilesState.groupSubId` 的一次快照；`newDraft` 继承快照。
- 输出：`bridge.importFromText(text, subid: 快照, deduplicate: true)`；`persistImportedProfiles` 对空 `subid` 的返回 DTO 补快照组；`saveDraft`/`deleteSelected` 走既有 SQLite 路径。
- 错误：导入沿用 `describeImportFailure`；删除失败如实提示；活动节点 apply 失败保留 runtime 结构化错误，不谎报完全成功。
- 取消：粘贴/扫码/编辑取消不落盘（既有行为）；删除确认取消不落盘。
- 权限：仅本机 UI + FRB/Rust/SQLite；不启动内核、不监听端口、不写系统代理/TUN。
- 持久化：SQLite（`ProfileItem.Subid`）；重开后仍在当前组。
- 生效：编辑/删除活动节点调用 `RuntimeController.applyActive`；删除后按 `SetDefaultServer` 回退并 apply，无候选则清空活动（不 apply）。
