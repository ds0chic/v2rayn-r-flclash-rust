**1. 元素行为固定方法**

每个窗口/菜单/表格/设置字段按四份台账的精确ID和源符号绑定P00–P25规则；布局、菜单位置、默认列顺序、设置分组及原快捷键不因修交互自行重排。一个action的菜单、快捷键、托盘、行双击必须共用一份语义。设置窗口的草稿、保存、取消以本产品原版为准；不用SteamBox即时保存模式。

以下规则是重构目标，不能用当前有缺陷实现反向定义需求：

| 元素/动作 | 固定的目标与反馈 | 返回/失败/重开 |
|---|---|---|
| 订阅组标签与当前组动作 | `groupSubId`为同一权威当前组；新增/导入/更新当前组均捕获该ID；订阅编辑窗口选中行不替代主表当前组 | 修改组后同步重派生组名/计数/节点/selection；删当前组按原版fallback，不能留下隐形过滤 |
| 添加/剪贴板/文本/文件/拖放导入 | 解析、实际保存、失败数分别显示；目标组冻结，追加/替换按各源action明确区分 | 不为修归属调用会替换整组的API；保存失败保留输入；写成功后按同组重取并重开确认 |
| 设为默认/激活/运行切换 | 幂等“设为默认A”再次执行仍为A；与启停/应用按原action协调，desired和applied独立 | 默认徽标不是内核已运行证据；B失败时保留真实旧运行与待应用事实 |
| 节点表点击/Shift/右键/键盘 | focused/anchor/selection分离；复制按原Ctrl+C，不变成克隆；右键精确目标；文本输入焦点优先编辑 | 刷新保留组/筛选/排序/滚动；隐藏selection不被误用于批量动作；按ID排序与删除 |
| 搜索/过滤/布局切换/页内tabs | 输入文字和实际过滤来自同view状态；IME结束按源触发条件查询；三布局切换保持上下文 | 返回不能过滤框空白却旧过滤仍生效；layout值统一存储，不由settings.load恢复旧副本 |
| 编辑节点→保存→立即应用 | 保存回执带新desired revision；运行请求等权威快照或直接用同一回执revision | 旧事件不回滚新草稿；失败保留可重试状态；不能以陈旧revision报莫名失败 |
| 参数设置/保存/应用/取消 | draft、saved、desired、applied分层；应用处理最新有效draft；自启等系统效果只在合法提交点执行 | 保存中再编辑不丢新输入；取消撤草稿；既有已提交效果明确，不能声称取消已撤销 |
| 快捷主题/布局/双击设置 | 与参数窗口共用canonical字段；快捷修改回写同字段，窗口初始读新值 | load不得覆盖快捷修改；重开和显示设置保持同值，双击行为按冻结值 |
| 测速菜单/设置/目标集合 | 使用已保存URL、超时、并发、分页等真实字段；目标按各ACT的scope明确枚举 | 空选择不得被后端默认为全库；“当前可见”保持过滤/当前组边界；部分结果逐行保留 |
| 测速开始/停止 | 一个有可见目标的job；重复同目标去重，多个job需明确管理；停止只是请求，终态确认后展示已停止 | 切页仍可定位原job；不覆盖唯一jobId后遗留旧任务；取消不抹已完成测量 |
| 订阅更新/导入/取消 | 接受时即返回operation/job ID，完成通过事件或可查询结果；各入口更新同一投影 | 回执丢失按request查，不重复下载写入；取消有可取消阶段与确认，不取消已完成旧job冒充通过 |
| 路由/策略组/子节点/导入编辑 | 源ACT决定规则顺序、选择范围、复制/导入格式；编辑draft；依赖目标存在并校验引用 | 过滤后的拖拽不能悄悄改变全库；提交后重开顺序与最终内核配置一致 |
| Clash代理组/连接/日志/统计 | runtime拥有真实状态；选择代理/关闭连接用稳定ID+runtime epoch；轮询/流式投影有界 | 页面隐藏停绘制与订阅而任务继续；旧epoch结果拒绝回写，断连不造空列表/已停止 |
| 系统代理/TUN/入站/DNS/证书/核心 | 按冻结字段与平台能力显示，已保存不等于平台已生效；只有实际owned资源结果才成功 | 权限拒绝/部分完成/恢复失败有持久结果；本轮不得测试宿主代理或10808 |
| QR/分享/更新/托盘/权限窗口 | 源目标、格式和关闭策略保留；外部交付与业务完成分开；版本/下载/校验/重启阶段可见 | picker/挑战取消不改旧值；更新失败保留可用版本；隐藏/第二实例不重复内核 |

没有在表中单列的动作仍受其精确`compat/actions.yaml`记录约束，不能当自由设计空间。台账中尚未定位或平台差异条目保持原状态，追加发现；不得为让比例好看删行。执行模型必须生成逐元素action/field/route映射，未解析元素不能记verified。
