## 4. 布局与持久化结论

- 三布局（widget test `t05_shell_chrome_test.dart`）：
  - 默认 **Vertical**（LAY-MAIN-002，上游 default:true）：上节点表 + 下 TabStrip 在左。
  - 工具栏「主界面布局」切换 **Horizontal**：左节点表 + 右 TabControl（信息/当前代理/当前连接在上）。无需重启。
  - **Tab**：配置项/信息/当前代理/当前连接 平级，TabStrip 在左（LAY-MAIN-003）。
- 分隔条：水平/垂直分隔条可拖动；比例写入 exe 同目录 `ui_state.json` 的 `layout.horizontal_split` / `layout.vertical_split`，重开由 `UiShellController.build` 恢复（测试用同一 `MemoryUiStateStore` 新建容器校验）。
- 列管理（`t05_profiles_ui_test.dart`）：列宽拖动、列显隐、列顺序均写 `ui_state.json` → `column_layout{order,visible,widths}`；重开恢复。列顺序/显隐经列设置对话框与控制器操作。
- 排序：稳定排序（相等键保持原相对序，`t05_sort_stable_test.dart` 断言）；点表头后选中集（按稳定 id）保持不变；排序后按锚点行 id 回跳到原顶部行（`_sortWithAnchor`，视图锚点保持）。
- 右键：保留现有多选（scope 规则），并弹出 ledger 条目菜单（编辑/移除/测试/移至上下的 T/U/D/B 真实重排/全选/分享/导出/生成策略组）。
- 快捷键作用域：过滤框聚焦时 Ctrl+A / D 不触发表格动作（HKR-001/002，`t05_profiles_ui_test` 与 T01 `profiles_filter_test` 双覆盖）。

状态栏无假状态断言：速率显示 `--`、运行节点 `未运行`，断言不含 `已连接`。系统代理四模式（清除/自动配置/不改变/Pac）仅切换 UI 状态并提示「后端接入见 T13」；TUN 开关提示未接入；路由/节点/运行信息占位。
