## 修复合同与实现

1. **接口发现替代人工 env**：`tun_plan::tun_hints_from_env()` 不再只读 `V2RAYN_R_TUN_INTERFACE_INDEX`；新增 `discover_interface_index(adapter_name)`（Windows 走受控 `netsh interface ipv4 show interfaces` 查询，`CREATE_NO_WINDOW`）与纯函数 `parse_interface_index(output, name)`（unit-testable；按名匹配、支持空格名、跳过表头），`resolve_interface_index(adapter_name, explicit)` 让显式非零覆盖优先，否则发现，未知适配器保持 `0` 并由 `tun_spec_from_settings` 响亮拒绝（不猜 index）。
2. **UAC/runas 授权与取消分支**：`helper_client::launch_helper` 从普通 `Command.spawn` 改为 `elevation::shell_execute_runas`（直连 `shell32!ShellExecuteW` + `runas` 动词，`SW_HIDE`）。用户取消（UAC `ERROR_CANCELLED=1223`）→ 结构化 `error.tun_helper_denied`（同一稳定码 `E_TUN_HELPER_UNAVAILABLE`），不留半成品；其它 `ShellExecuteW` 失败 → `error.tun_helper_unavailable`。**绝不降级为未提权直连 TUN 路径**。
3. **handshake token 从配置生成**：`HelperConfig::effective_token()` 在 operator 未设 token 且允许自动启动时生成进程稳定 token（`generated_helper_token()`，pid+单调时钟，不落日志）；`PipeHelperLink::identity`/`ensure_connection` 使用之。helper 通过命令行 `--serve --token <t> --run-roots <r>` 接收（UAC 不转发环境变量），`privileged_helper::main` 同时保留 legacy env 兼容。`HelperConfig::from_env` 新增 `default_helper_bin()`：打包安装中 `privileged_helper.exe` 与 `net_host.exe` 同目录时自动发现，普通 RC 无需 `V2RAYN_R_HELPER_BIN`。
4. **按 snapshot 事实报错**：关闭/失败不谎报。Rust 侧既有 `reconcile_applied_session`（`Stopped|Degraded|RollingBack` 撤下 applied 端点）与 `apply_plan` 的 RR-10 恢复路径保证：helper 失败在核心 spawn 前回滚（`E_TUN_HELPER_UNAVAILABLE`），old session 已停则如实 `Stopped`，可恢复则 `try_restore`。本卡未改 Dart（`status_bar_view.dart` 仅提示的问题是 Flutter 侧登记缺口）。
5. **真实 TUN 设备创建/路由下发 blocked**：`services/privileged_helper/src/windows.rs:408-420` 仍是给**已有** interface 写地址；设备本身由核心创建的合同与“helper 写地址先于核心 spawn”的顺序未在无授权隔离主机上解决。保持 blocked 登记（见下）。

输入/输出/错误/取消/权限/持久化及生效语义：
- 输入：`TunModeItem`（持久化）+ 适配器名；线索 `V2RAYN_R_TUN_ADAPTER`（可选）；显式 `V2RAYN_R_TUN_INTERFACE_INDEX`（仅测试/隔离覆盖）。
- 输出：`TunSpec.interface_index` 来自 OS 发现；helper 经 UAC 启动并完成 token 握手；`RuntimePlan` 带真实 `tun` 节点。
- 错误：未知适配器 → `error.invalid_tun_setting`（field `interface_index`）；UAC 取消 → `error.tun_helper_denied`；helper 不可达 → `error.tun_helper_unavailable`；均不降级、不谎报。
- 取消：UAC 取消即返回，不 spawn 核心，无残留 journal（helper apply 前失败路径已 `finalize_journal` + 清 staging）。
- 权限：helper 仅经 `runas` 提权，net-host 普通权限；测试不触发真实 UAC。
- 持久化：无新增持久化；`TunModeItem` 不变。
- 生效：TUN 打开时下一次 `build_runtime_plan` 即用发现到的 index。
