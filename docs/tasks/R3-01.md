对应 feature / field / action：`RR-03`、`F-SYSPROXY-001`、`ACT-STAT-001`、ACT-TRAY-005；字段 `FLD-CFG-...`(SystemProxyItem.SysProxyType)。

输入、输出、错误、取消、权限、持久化及生效语义：
- 输入：应用会话实际端口（合成 Runtime 端口 ≥ 11808）与 PAC 模板文本。
- 输出：PAC 服务返回体中 `__PROXY__` 被替换为完整合法指令 `PROXY host:port;DIRECT;`（SOCKS 端点见 R3-PROXY-UI 用 `SOCKS5`）。
- 错误：无运行会话时不启动 PAC，结构化 `E_NO_RUNNING_SESSION`；文件读取失败保持结构化错误。
- 权限：`None`；测试只用 fake bridge，不写系统代理、不监听 10808。
- 持久化：`SystemProxyItem.SysProxyType` 在成功路径保持原顺序（先保存模式）。
