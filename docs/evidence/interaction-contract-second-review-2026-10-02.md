## 2. 每个元素必须绑定完整动作规格

按钮、开关、菜单项、双击、拖放、快捷键、托盘、URI、文件返回、计时触发均有稳定 action ID。每项必须填写下列字段，任一空缺不得进入 `verified`：

| 项 | 必须确定的内容 |
|---|---|
| 入口与目标 | 产品基线符号、可达条件、稳定目标 ID、目标范围、账号/AppId/资源上下文；不使用显示昵称、数组索引或当前焦点推导已提交目标。 |
| 先决与冲突 | 是否需要 Steam/权限/运行能力；冲突资源键；重复是否合并、拒绝或安全重试；真实失败语义。 |
| 提交与效果 | typed command、草稿边界、持久化目标、实际应用目标、成功核对条件、必要重启。 |
| 生命周期 | 页面关闭、窗口隐藏、应用退出时继续/取消/清理哪一层；可取消阶段、补偿结果、结果未知的核对方法。 |
| 反馈与时间 | 按下、送出、接受、运行、已保存、已应用、失败、未知对应的用户文案；逐阶段有限数字超时；有无真实总量。 |
| 输入与恢复 | 键盘/焦点/选择范围；失败后保留什么；刷新、重开、事件丢失时如何恢复。 |
| 证据 | 正常、重复、冲突、取消、失败、重开及适用平台效果用例；以结果为断言的证据路径。 |

说明性标签、纯图标、disabled 元素也要有明确含义；禁用应可获得简短原因。装饰元素不得使用手型、按钮语义或交互焦点暗示尚无实现的动作。产品开发说明、内部 message key、任务编号不进入普通用户提示。

## 3. 状态来源与反馈不能混层

Flutter 只拥有草稿、焦点、选择、滚动、临时输入反馈。AppEngine 拥有业务实体、持久化事实和 operation；net-host 拥有监听及已应用网络状态；steam/vendor worker 拥有实际会话和外部执行结果。UI reducer 不能通过启动动效、设置 boolean、收到非空 callback 或计时结束制造业务事实。

动作还需按效果分型：纯导航/焦点/弹层的 `local_ui` 以本地UI结果结束，不虚构Rust调用；`read_query` 使用query ID与快照且不得写业务库；`domain_command` 与 `external_effect` 经过权威服务。下表的接受/保存/应用按动作适用；需要恢复的副作用operation要持久记录，普通搜索查询不因统一协议被强制逐次持久化。纯UI本来已完成的结果不显示“等待后台确认”。

| 状态/反馈 | 可展示的证据 | 不得推导出的结论 |
|---|---|---|
| 按下 | 有效控件收到键鼠输入并在下一可绘制帧反馈 | 请求已到 Rust、已保存或已生效。 |
| 正在提交 | Flutter 已创建 request ID 并送出命令 | AppEngine 已接受；按钮可以临时阻止同次派发，但不能显示领域“运行中”。 |
| 已接受 | AppEngine 验证命令外壳并记录 operation ID、目标及上下文；回执带 request ID | 前置检查/外部动作已经成功。 |
| 进行中 | operation 的 validating/running 阶段及实际步骤事件 | 有真实百分比或当前目标已经应用。 |
| 已保存 | 权威存储事务提交，回读该 revision 对应值；可在重开后恢复 | 网络、Steam、平台系统变更已经完成。 |
| 已应用 | 对该 revision/operation 的实际效果核对通过 | 外部云已同步、Steam已经登录、任务永远不会再失败。 |
| 失败/部分完成 | 权威错误和已提交/未完成步骤 | 全部自动回滚，或草稿应被丢弃。 |
| 结果尚未确认 | 命令回执丢失或外部副作用超时，不能证明未执行 | 操作失败、操作已取消或可以自动再做一遍。 |

运行状态至少包括 `queued → validating → running → succeeded / failed / cancelled / unknown_result`；另有真实 awaiting_user/challenge 时必须显式表达等待谁、还需做什么。一次 operation 只有一个当前权威状态；UI 等待态不伪装为该状态。

网络必须独立展示 saved/desired/applied revision 与 runtime epoch：配置已保存但 apply 失败时提示“已保存，应用失败，仍在使用上一配置”，保留正确已保存值及真实旧运行状态。启动成功至少需监听 ready、规则探测和适用资源安装完成；停止成功至少需接入撤销与自有资源清理核实。账号切换则以重新连接后的实际 SteamId 为依据；VDF MostRecent、成功启动进程、avatar变化均不能代替登录成功。Cloud 接口写入与云同步分别表达。挂卡完成必须来自合法完整徽章快照，空解析/限流/登录页不是完成。

事件携带 schema version、epoch、sequence、operation ID、entity ID、account epoch 和所需 revision。旧 epoch/账号上下文的结果拒绝回写；sequence 跳跃、重连或进程重启先取权威快照。快照与后续事件需有无间隙接续点，不能“先订阅后取快照”覆盖新状态，也不能“取完再订阅”漏变化。重连期间保留最后已知值并明确暂未核实；不把断连改成 stopped 或空库。

## 4. 重复、冲突、取消与未知结果

1. 所有入口调用同一领域用例。UI 避免同个手势重复派发，Rust 用 request ID 和 operation 记录兜底；同 request ID 的重复投递返回原 operation，不再做副作用。双击不能同时被 XAML/手势层/codebehind 处理两次。
2. 同动作同目标在运行中再次触发，显示现有 operation；相冲突动作默认拒绝并指出当前任务，只禁用该冲突资源的操作。需要排队或最新意图替换的动作必须在动作规格写清，UI 显示已排队目标；禁止后台默默排队或丢弃最后一次意图。
3. 不使用所有按钮共用 300ms/500ms debounce。搜索/文件 watcher 可合并过时查询；查询需要 query ID 与取消令牌。外部账号切换、云写入、删除、启动/停止不能靠时间窗防重复。原 SteamBox 打开目录按路径 7.5 秒限制属于特定基线事实，应单独审阅，不扩展成全应用规则。
4. 取消请求立即显示“正在取消”；只有后端确认未提交副作用，或补偿/自有资源清理已完成，才能显示已取消。失去窗口、取消等待、断开桥、超时都不等于取消实际业务。已越过不可回滚点则显示实际结果并继续核对，不提供虚假取消成功。
5. `unknown_result` 冻结同一副作用的自动重试；按原 operation/query/身份重新检查外部结果。仅已证明未生效或操作本身有经验证幂等性，才允许重试。重试按钮带原目标和明确政策；不得用 `retryable=true` 一项覆盖这些差别。
6. operation journal 保存可恢复身份和步骤，不保存原始 token/cookie/秘密参数。进程重启先核对未终结任务、实际 worker 和已写资源；历史“运行中”不直接恢复为当前运行。

## 5. 焦点、键盘与选择

| 情况 | 共用确定规则 |
|---|---|
| Tab/Shift+Tab | 按可见、可操作元素的稳定视觉顺序移动；disabled/纯装饰不占焦点。弹窗圈定焦点，关闭后恢复到发起控件，若已消失则最近合法替代控件。 |
| Enter/Space/Escape | 聚焦按钮用正常激活语义，仅执行一次；文本编辑/IME组合优先于应用命令。Enter 只提交当前合法默认动作；多行文本不被抢。Escape 先处理当前输入/菜单/可关闭弹层；不默默停后台任务，也不隐式撤销已写系统。 |
| 菜单/悬停动作 | 键盘可进入，菜单打开后焦点在菜单，关闭恢复发起处。悬停才出现的按钮不能成为唯一入口。打开上下文菜单不执行命令。 |
| 异步更新 | 不抢输入焦点、不把列表滚回顶端、不跳路由。必要的验证错误将焦点移到第一个错误字段；这是显式提交的结果，非后台事件。 |
| 快捷键范围 | 文本框 Ctrl+C/V/A 等先由文本编辑处理；列表命令仅在列表焦点范围执行；全局命令还需模态及 IME检查。每个产品仅开放有基线或已批准增强记录的键位。 |

列表维护独立 `focusedId / anchorId / selectedIds / queryScope`，全部为稳定 ID。以下是修复当前 v2rayN 选择缺陷的明确目标；SteamBox仍需在对应列表与原框架行为比对后登记采用情况：

- 普通点击选择该行并更新焦点/锚点；Ctrl点击增删该行且更新焦点与锚点。Shift范围围绕固定锚点按当前排序计算，重复Shift不让锚点漂移；Ctrl+Shift在原集合上添加该范围。键盘Shift方向移动焦点并更新范围；目标离开视口时最小滚动保证可见。
- 排序或同一 queryScope 的数据刷新保留仍存在的稳定选择和焦点，重算范围顺序；对象被删除后移除其选择，焦点落到原位置最近合法行。仅未挂载/不在当前分页不会失去选择。
- 订阅分组、平台、账号、筛选范围变化形成新 queryScope，默认清除选择/锚点并设置新的合法焦点；不携带旧范围隐形目标。确有原版跨范围选择时必须显式呈现总数、不可见数量与清除入口，所有批量动作显示同一精确目标集合；不得把此例外变成未声明默认。
- Ctrl+A覆盖当前已确定结果范围，而不是当前渲染 Widget 或单一分页；后端提供总数/选择集合或同版本选择谓词。Shift跨未加载页不能猜索引或只选已加载部分。三态全选基于同一目标范围。
- 右击已选行保留多选；右击未选行将上下文目标收敛到该行并同步选择。提交后冻结目标集合与 query revision；刷新、鼠标移动或账号变化不得扩大已提交批量目标。
- 所有 reload、保存返回、测速/扫描事件只更新权威数据，再经同一筛选/排序/分页派生流程。不能有一条 reload 绕过分组过滤。

## 6. 草稿、保存、应用与导航

草稿至少记录 base revision、draft revision、dirty fields 与 validated errors；已保存值、已应用值和当前草稿分别保存。提交过程只锁定冲突提交，仍可读数据或操作无关页面。保存期间再次编辑必须保留新草稿，回执只标记该次提交覆盖的字段，不能把未提交的新输入清成 clean。

| 字段/编辑模式 | 确定行为 |
|---|---|
| 有保存/取消的编辑 | 改动只进草稿，文件picker也只填草稿。取消/丢弃不执行系统写入。校验失败保持输入、定位字段；保存冲突保留输入并给出已改变的字段，不盲目覆盖新 revision。 |
| 保存后再编辑并应用 | 应用先校验并提交最后一轮草稿，再对返回的准确 revision 请求效果；不能读旧 snapshot、应用旧草稿或为了消除 stale 错误移除并发检查。失败保留草稿和可重试的实际阶段。 |
| 原即时生效字段 | 有效值触发真实持久化/效果，用字段旁状态表示失败；滑块本地预览可立即更新，持久化可有界合并但必须提交最后值。没有“取消全部撤销”的虚假按钮。普通开关不加确认弹窗。 |
| 下次启动/必须重启字段 | 保存成功后持续标明何时生效；运行值不改成新值，提示不阻塞其它正常工作。 |
| Steam游戏元数据两阶段 | “保存到本应用overlay”与“应用到Steam”分别有真实结果，原取消/重置/备份语义保留。不能第一次保存后显示全部已应用。 |

页面离开不得默默丢草稿：普通导航保留低成本内存草稿，返回恢复，这不构成业务“已保存”；明确取消可丢弃。有原版要求的破坏性离开确认照基线保留，不给普通切页新增模态确认。密码、PIN等敏感输入只保留必要短期内存，页面结束按其契约清除，不作为持久化页面草稿。

顶层同页点击幂等；根导航不无限叠返回栈，子导航返回次序固定，模态返回先关闭顶层弹层。SteamBox设置为一个长页五锚点，锚点跳转与手动滚动联动，不拆五路由；模块内部原禁堆栈tabs保持其语义。返回恢复必要筛选/滚动/草稿，不要求保留整棵Widget树。

## 7. 外部登录、文件选择与外部打开

- 文件选择一次只开一个对应picker，锁定发起按钮；取消是正常返回，无错误toast、无提交。返回携带发起页面/草稿代号，仅同一仍有效编辑接收；离页或账号变化后旧结果丢弃，不覆盖新草稿。路径存在、类型、格式、权限由真实后端检查。程序路径无效仍可取消，不把用户关在路径设置弹窗。
- 外部浏览器/Steam登录打开成功只显示“已打开，等待登录”；挑战有 operation/challenge/account epoch、过期时间、允许重送点。成功回执需正确会话与身份核对；扫码/验证码/邮箱验证不是本地OTP功能。失败留在原流程并说明需重试、换账号或重新登录；限制和退避不能无限循环。
- 登录窗口关闭按动作规格取消尚未提交的挑战；已发送外部动作仍按真实后果核对，不承诺回滚已有会话。旧challenge返回不污染新账号。关闭UI不自动退出已有有效会话。
- 打开目录、链接、Steam安装/运行URI的反馈只承诺系统受理或可核实结果；返回一个进程句柄不等于游戏已运行、页面已加载或账号已登录。提交前冻结结构化参数和目标，禁止命令字符串拼接。
- 云上传picker返回后仍需展示真实文件/覆盖范围和原有必要确认。确认仅用于原有外部破坏性操作及已列明安全改进；查看详情、读库、普通开关、无副作用picker不增加确认。

## 8. 页面、窗口与后台任务

| 事件 | 必须行为 |
|---|---|
| 页面dispose/切tab | 解除视图订阅并取消过时页面查询；不停止用户已启动加速/挂卡/AFK，也不解除其后台资源owner。页面再进取快照并显示实际状态。 |
| 工作窗口关闭 | 页面只读查询可取消；已接受业务任务按其明确生命周期继续或请求取消。不得仅因callback视图销毁将真实操作当成功或取消。继续任务能在原模块/全局任务状态找到。 |
| 主窗X且托盘开 | 按SteamBox基线隐藏主窗，后台继续；恢复重连快照、保持正常窗口焦点，不能新启动重复任务。 |
| 主窗X且托盘关；显式退出 | 执行AppEngine退出流程，停止自有任务并撤自有接入；失败显示需要恢复的步骤并保持恢复入口，不消失后留Hosts指向死进程。无需普通退出额外确认。 |
| 手动启动/显式silence | 手动显示；silence按基线最小化/后台。TrayIcon开关×两种来源四格都验收。第二实例通过IPC唤回/派发一次，不静默吞命令。 |
| 崩溃/重启/sleep/wake | 依据journal与实际worker/Steam身份/监听重新核对；计时采用单调时钟；不可把旧running字段直接当作仍运行。恢复只处理自身资源与经过授权的精确目标进程。 |

平台退出/强制结束无法保证完成同步清理时必须有可回放journal与下次恢复证据，不能用“退出成功”文案替代资源检查。任务所有权独立于页面：AFK/挂卡共享worker需引用计数，停止一个不停止另一个或用户游戏。

## 9. 时间预算与测量

以下为SteamBox原方案既有初始目标，均未实测。具体硬件、数据、版本和预算必须在优化前冻结；失败后不降低门槛或选单次最好成绩。

| 区间 | 初始门槛/目标及精确终点 |
|---|---|
| 键鼠输入→首帧反馈 | 普通反馈≤100ms；记录OS/测试输入时间到反馈帧呈现，不能从controller调用后才开始计时。 |
| 导航→可交互 | 缓存页面p95≤150ms；终点为目标可见内容与目标控件可用，不只route变更。 |

| 冷/热启动 | 冷启动首窗可交互p95≤1.5s且对比原版改善20%为目标；热启动/唤回p95≤350ms；计入worker/IPC必要就绪。 |

还需冻结每种外部动作的等待上限、取消确认上限和未知结果核对上限；未填写数字的动作不通过性能/可用性门禁。UI局部输入反馈不能等待该上限；超过阶段deadline显示真实超时/核对状态，不伪报后端已经停止。真实百分比只在已知完成单位和可信总量时显示；多阶段操作注明当前阶段，不把某一子阶段100%显示成整项完成。

## 10. 全流程门禁与防钻空子

1. **分母先行。** 逐个穷举可达绑定、菜单、代码事件、托盘、协议、后台触发，给每个 action与字段独立ID。菜单存在、命令定义存在、布局截图存在不能代替可达或效果。发现只追加；保留项目不得以not_applicable、隐藏UI或删除入口降低分母。
2. **同一真实链路。** 正常功能必须从真实Flutter入口，经发布同款Rust bridge、实际业务、隔离持久化、重开，再核对真实配置/平台/原生/网络效果与反馈。fake bridge、echo、lastEvent、仅mock调用次数不计正常功能通过。故障注入单独标注。
3. **断言实际结果。** Ctrl+C检查剪贴板与未增加节点；分享检查窗口内容；排序检查存储、刷新、重开；设置检查最后草稿、desired/applied版本；账号检查实际SteamId；Cloud检查正确账户/AppId与外部读回；启停检查owned资源。测试不能只镜像实现、相信toast或以日志事件名作唯一结果。
4. **每条动作的反例。** 同目标重复、冲突目标、发送后断桥、事件乱序/丢失、取消前/后提交点、超时未知、账户变更、离页/重开均有适用用例；未适用要写源证据，不批量省略。错误路径仍能继续其它正常操作。
5. **整个版本复验。** 测试报告绑定源码/二进制hash、环境、fixture、入口与结果。旧commit绿灯不可给当前版本背书；Flutter integration_test不覆盖所有原生窗口/托盘/UAC，人工及平台证据缺口明确未验证。
6. **真实外部条件不可替代。** Steam ABI/合法服务/SDK及系统接入需获授权的隔离环境真实验证；没有环境则blocked并说明功能影响。mock只证明故障反应，不能将该功能标verified。普通CI阻止真实系统/外部写入；测试端口预探测且≥11808，绝不触碰10808或宿主系统代理。
7. **负门禁。** 三删除模块无编译/包/设置/route/托盘/URI/CLI/初始化/计时器/请求/专属迁移，残留目录与更新不能复活。仅搜索模块名为零不充分：须比对发布manifest和实际启动注册/任务清单；同时共享登录及权限正向用例仍通过。
8. **可用性与视觉独立。** 表格密度、DPI、字体、减动画验证不能把100%按钮有动效计为100%业务完成；美化不延迟真实业务、不引入伪进度。流程完整率只用已冻结适用流程总数与真实通过数计算，未测、blocked、preserved_only明确列出。

对当前v2rayN审查应优先将UX-001/002、003、004/008、005、006/007/009分别拆为结果可核对的任务卡；旧测试绿灯只保留其实际覆盖结论。对SteamBox则先完成S00/S02的产品快照/分母，再把上述规则落到S04/S05/S08与领域纵向卡，不以本报告替代原版运行盘点。
