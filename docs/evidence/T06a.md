## 4. 11 协议表单字段覆盖统计

顶层字段（所有协议）：ConfigType（新增时可选）、CoreType（能力约束）、备注、地址、端口 —— 5 项。

| 协议 | 协议专属字段数 | 覆盖字段 |
|---|---|---|
| VMess | 3 | UUID / AlterId / VmessSecurity（加密方式） |
| VLESS | 3 | UUID / Flow / VlessEncryption |
| Shadowsocks | 2 | SsMethod / Password |
| SOCKS | 2 | Username / Password |
| HTTP | 3 | Username / Password / HttpHeaders |
| Trojan | 1 | Password |
| Hysteria2 | 9 | Password / SalamanderPass / Ports / UpMbps / DownMbps / HopInterval / Hy2RealmUrl / GeckoMin/MaxPacketSize |
| TUIC | 3 | Password(UUID) / CongestionControl / Uot |
| WireGuard | 7 | Password(私钥) / WgPublicKey / WgPresharedKey / WgInterfaceAddress / WgReserved / WgMtu / WgDns |
| AnyTLS | 1 | Password |
| Naive | 4 | Username / Password / InsecureConcurrency / NaiveQuic |

传输字段（按 `Network` 能力）：raw(3: RawHeaderType/Host/Path)、kcp(3: KcpHeaderType/KcpSeed/KcpMtu)、
ws|httpupgrade(2: Host/Path)、xhttp(4: Host/Path/XhttpMode/XhttpExtra)、grpc(3: GrpcAuthority/GrpcServiceName/GrpcMode)。

TLS/Reality 字段：StreamSecurity / AllowInsecure / Sni / Alpn / Fingerprint 恒有；Reality 选中时追加
PublicKey / ShortId / SpiderX / Mldsa65Verify；另 Cert / CertSha / EchConfigList / VerifyPeerCertByName。
SecurityParams 共 13 字段全部可编辑。

- ProtocolExtraItem：30/30 字段在 `ProtocolExtraDto` 与表单/持久化中可往返；
- TransportExtraItem：11/11；
- ProfileItem 顶层：40 列全部在 `row_from_profile`/`profile_from_row` 映射（legacy 列进 `Profile::extra` 保留）。

无「大 JSON 文本框」代替表单；未知扩展仍以 `extra_json` 原样保留。
