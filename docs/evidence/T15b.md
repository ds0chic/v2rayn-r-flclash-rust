# T15b 证据 — 测速与结果闭环（TCPing / 真实延迟 / 下载速度 / 混合 / 快速真实延迟 / 取消 / 无效清理 / 结果列）

本回合为 T15b 实施子代理（deepseek-v4.1-flash）交付。目标：把测速做成
`JobId + CancellationToken` 的任务框架，TCP/握手类与下载类使用独立并发池，
结果经 `ProfileExItem` 闭环写回节点表 Delay/Speed/IpInfo，支持取消、无效清理，
真实延迟 / 下载 / 混合经 net-host 受限测试会话（独立端口 ≥ 11808，主会话隔离）
运行临时内核。**不假进度/假结果；不绕过 net-host 直接启动内核；不占用 10808；
不 commit。**

## 1. 改动文件与接线点

### Rust — application（测速核心）

- `crates/application/src/speedtest.rs`（新增，约 1500 行）
  - `SpeedTestSettings::from_item`：按 `domain::SpeedTestItem` 归一化
    （timeout ≥ 10s、MixedConcurrencyCount ≥ 10、page size 默认 1000、URL 回退）。
  - `SpeedTestRunner::run`：`SpeedTestAction`（Tcping / Realping / UdpTest /
    Speedtest / Mixedtest / FastRealping）统一入口；`SpeedTestSnapshot`
    冻结节点集合与源版本；结果按 50–100ms 批次（`BATCH_FLUSH_MS = 75`）经
    `on_batch` 回调冲刷；初始 `Speedtesting` 状态一次批量下发。
  - 独立并发池：TCPing 用 page-size 池；Realping/FastRealping/下载/混合用
    `MixedConcurrencyCount` 池（每节点一个临时内核，见决策 ADR）。
  - `SpeedTestSession` trait：`open / real_ping / download / udp_ping / ip_info /
    close`；`SessionGuard` RAII 保证失败/取消也清理临时内核。
  - `tcping`：真实 `TcpStream::connect_timeout`，超时/失败返回 -1；loopback
    亚毫秒结果按 ≥1ms 上报以免与“未测试(0)”混淆。
  - `http_get_via_socks`：真实 SOCKS5 握手 + HTTP/1.0 GET，按 250ms 轮询读取，
    取消即时；下载按 `body_bytes / seconds` 计算 MB/s（对齐上游
    `DownloaderHelper` 的 `maxSpeed/1000/1000`）。
  - `ProfileExStore`：`apply / apply_all / remove_invalid / clear_statistics`；
    `remove_invalid` 删除 `delay == -1` 行。
  - `SpeedTestJobs`：`start / get / cancel / finish / active_count`。
  - `find_free_test_port`：≥11808、跳过 10808。
- `crates/application/src/lib.rs`：注册并再导出测速 API。
