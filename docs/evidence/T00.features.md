## 3. 内核支持深度推导依据

判定依据（均来自源码分支/支持集/更新集，不是猜测）：

1. **结构化生成**：`CoreConfigHandler.GenerateClientConfig` 仅三分支——`Custom` 走自定义；`RunCoreType==sing_box` 走 `CoreConfigSingboxService`；其余走 `CoreConfigV2rayService`（`CoreConfigHandler.cs:16-31`）。因此只有 Xray（及同分支的 v2fly）、sing-box 有完整结构化生成；mihomo 仅对 Custom 做 YAML 局部改写（`CoreConfigClashService.cs:15`）；其余内核只能作 Custom 透传。
2. **可编辑配置类型**：`Global.XraySupportConfigType` / `SingboxSupportConfigType` / `SingboxOnlyConfigType`（`Global.cs:366-393`）决定哪些协议由哪个内核生成。TUIC/Anytls/Naive 为 sing-box-only。
3. **内置更新目标**：`CoreInfoManager.IsCheckUpdateSupported` 仅 `v2rayN/Xray/mihomo/sing_box` 为 true（`CoreInfoManager.cs:75-85`）；`GetCheckUpdateCoreTypes` 过滤 x86 与低版本 Windows 后再加入（`:53-73`）。其余内核无内置更新。
4. **应用更新与内核**：`v2rayN=99` 是应用自身更新标识；`CheckUpdateGuiN`/`ParseDownloadUrl` 中 `case v2rayN` 与内核分支并列（`UpdateService.cs:9`、`:291-297`），注释与方案第 12 节一致，不应视作代理内核。
5. **统计支持**：`StatisticsXrayService` 轮询 `http://127.0.0.1:{StatePort}/debug/vars`；`StatisticsSingboxService` 订阅 `ws://127.0.0.1:{StatePort2}/traffic`（各自 `Url` 属性行）。没有其它内核的统计实现；mihomo 的“统计”仅经由 Clash API 的 `/proxies`、`/connections`（`ClashApiManager.cs:11-196`），与流量统计不是同一条链路。
6. **版本参数**：`CoreInfo.VersionArg` 仅 v2fly+v2fly_v5+Xray+mihomo+sing_box 有值（`CoreInfoManager.cs:128,142,165,189,234`），其余为 null，`GetCoreVersion` 仅对这些内核可跑。
7. **启动方式/特殊处理**：来自 `InitCoreInfo()` 每条的 `CoreExes/Arguments/Environment/AbsolutePath/LockedMaxVersion`（`CoreInfoManager.cs:104-292`），含 sing-box v1.14 上限、mihomo `-d` 便携目录、mieru 环境变量、brook 绝对路径、v2fly_v5 `jsonv5` 等。

## 6. 重要发现（Top 5）

1. **结构化生成实际只有 Xray/v2fly 分支与 sing-box**：`CoreConfigHandler` 三分支决定了 14 个内核里绝大多数只能作 Custom 透传，mihomo 仅做 YAML 局部改写（`CoreConfigHandler.cs:24-31`）。
2. **内置更新只有 3 个内核 + 应用**：`IsCheckUpdateSupported` 明确 `Xray/mihomo/sing_box/v2rayN`，且 `v2rayN` 受“非打包安装”限制；prerelease 仅 `v2rayN`、`Xray` 生效（`CoreInfoManager.cs:75-95`）。
3. **统计是双内核专用链路**：Xray 用 `/debug/vars`，sing-box 用 ws `/traffic`；其余内核无统计实现，mihomo 仅有 Clash API 的代理/连接视图（`StatisticsXrayService.cs:10`、`StatisticsSingboxService.cs:10`）。
4. **订阅更新失败保留旧节点是“早退”语义**：结果为空时在 `ProcessDownloadResult` 提前返回，不触碰节点；成功时 `AddBatchServers` 先按 subid 删旧再写新——成功即替换，非增量（`SubscriptionHandler.cs:197-216`、`ConfigHandler.cs:2049`）。
5. **TUIC/AnyTLS/Naive 是 sing-box-only**：`SingboxOnlyConfigType = SingboxSupportConfigType - XraySupportConfigType`，且 `AddTuicServer/AddAnytlsServer/AddNaiveServer` 强制 `CoreType=sing_box`（`Global.cs:393`、`ConfigHandler.cs:850,946,974`）。
