## 先处理的流程

| 顺序 | 用户实际操作 | 当前可确认的断点 | 详证 |
|---|---|---|---|
| 1 | 新装后下载内核并应用节点 | 下载落在 `<data>/cores`，net-host 默认搜索另一根目录；开发树 `tools/cores` 可掩盖 | [RR-01](runtime.md#rr-01--p1--普通下载核心后仍可能完全找不到它) |

| 3 | 编辑/删除活动节点、F5、托盘切路由 | 编辑/删除无共享 Reload；F5 仍占位；托盘只改路由编辑选中，状态栏设置默认仍未应用运行 | [RE-PROF-02](profiles.md)、[R-01](root.md)、[RR-02](runtime.md) |
| 4 | 更新多组订阅 | 一组成功、另一组失败/空URL时 UI 可将所有组显示 updated/成功；逐组错误丢失 | [SR-01](settings.md) |
| 5 | 导入原版 ZIP / 当前备份 | 原版资源文件未安装到 live data；提交 DB 后配置激活失败无回滚；恢复后主界面和运行会话未统一刷新 | [SR-02/03/04](settings.md) |
