### 1.1 幂等性

脚本连续执行两次均 exit 0，产物被覆盖重建（后续运行由 `-SkipBuild -SkipFlutter`
复用已编译产物，或全量重建）。两次 zip 的 SHA-256 **不同**
（历史 T20 首次 `4c88ed…`、重建后 `cf729e…`；2026-10-02 整改重建为
`8e01647b…`），原因是 `Compress-Archive` 在 zip 内写入文件时间戳。
**因此以成员内容清单哈希作为可复现性度量**。

### 1.2 包内容清单（成员 SHA-256，排序拼接后再 SHA-256）

稳定清单哈希（**排除 `build-info.json`**，因其含构建时间戳；
2026-10-02 整改重建值）：
`2d63ff9ad3775ca004fc2546c9267a6618d85f6185690e886315c9753029cd96`

复算口径（脚本化，成员数 24，包含 `LICENSE`/`NOTICE.md`/`README.md`）：
对包内除 `build-info.json` 外的每个文件取 `sha256(内容)`，输出行
`<hash>␠␠<相对路径>`（相对路径用 `\`），按行字典序排序，以 `\n` 连接并保留
结尾换行，UTF-8 编码后再 SHA-256。

包含 `build-info.json` 的整包成员清单哈希每次构建都会变，故不作为可复现度量。

## 3. Windows ARM64 尝试

命令（`apps/desktop`）：

```powershell
flutter build windows --release --target-platform=windows-arm64
```

结果（原文）：

```
Could not find an option named "--target-platform".
Run 'flutter -h' (or 'flutter <command> -h') for available flutter commands and options.
exit 64
```

`flutter build windows --help` 中无任何架构/`--target-platform` 选项；pinned
Flutter 3.47.5 的 Windows 桌面构建不提供架构选择。结论：**当前 CLI 不支持
直接产出 Windows ARM64**（需 ARM64 主机与相应引擎/工具链，本环境未具备）。
已写入 `compat/platform-matrix.md` §6（状态 `blocked`）。
