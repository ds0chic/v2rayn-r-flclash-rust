# T16 证据 — 备份/恢复/WebDAV/检查更新/内核更新接线

- 任务：T16 实施子代理（deepseek-v4.1-flash）
- 范围：`crates/application/**`、`crates/updater/**`（fetch 代理构造最小追加）、`crates/bridge_api/**`（含 FRB 再生成）、`apps/desktop/lib/**`、`apps/desktop/test/**`、`docs/evidence/T16.md`、`docs/decisions/T16-backup-webdav-update.md`、`compat/` 台账状态追加。
- 未改：`subscriptions`、`net_host`、`runtime`、`platform`、`core_adapters`、`privileged_helper`、`config_codegen` 的既有测试逻辑；未 commit。
- 安全约束：不触碰 127.0.0.1:10808 / 系统代理 / TUN。所有网络测试为 loopback mock（`tiny_http`，OS 分配的 ephemeral 端口）；所有落盘测试在 `tempfile` 临时目录。
- **未真实更新任何文件**：`apply_core` 仅在临时 cores 目录内 rename 交换；应用自身更新只返回 `ExternalUpgradeSpec`，不启动进程。

## 1) 文件与接线点

### Rust — application
- `crates/application/Cargo.toml`：新增 `updater`、`reqwest`(rustls, no default env proxy)、`zip`；dev 增 `sha2`/`hex`。

- `crates/application/src/webdav.rs`：`WebDavConfig`、`WebDavClient`（check/list/upload/download）、错误分类、`parse_propfind`。

## 5) 未决项

1. **签名方案未定（GPG/minisign）**：仍为 `UnsupportedSignatureVerifier`，不冒充已验证。→ 未验证。
2. **外部升级实跑未验证**：只构造并返回 `ExternalUpgradeSpec`，未启动外部进程替换运行中的 exe。→ 未验证。
3. **真实 WebDAV 服务器未实测**：仅 `tiny_http` loopback mock（含 401/超时）。真实 TLS/服务器差异未实测。→ 未验证。
4. **应用自身更新 UI 未接“执行”**：按边界要求只生成 spec；需外部 helper 落地后单独验证。
5. **定时任务未接线**：SCH-003 清理循环、SCH-004 每日检查更新仍为 identified。
6. **托管核心布局与 dev `tools/cores` 并存**：`installed_version` 兼容两种布局，但真实内核启动路径（net_host）尚未消费托管新布局，需后续整合验证。
7. 保留 T16-updater.md 其余未决项（跨卷交换、mihomo `.gz` 单文件、压缩比炸弹判定、真实签名）。
