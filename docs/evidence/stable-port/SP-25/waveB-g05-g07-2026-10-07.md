## Design (SP-00 conventions)

- Single owner: `crates/platform/src/http.rs` (`platform::http`).
  Layering: `application → {subscriptions, updater, platform}`; `subscriptions`/`updater` cannot use an `application`-owned facility without a cycle, and a new crate would need a workspace `Cargo.toml` edit (forbidden). `platform` is the only in-scope leaf all three can share, and it owns no subscription/node business (only transport), so it satisfies AGENTS.md layering.
- `HttpPolicy { timeout, connect_timeout, user_agent, proxy, trust, redirect }`:
  timeouts enforced on the reqwest client AND as an outer `tokio::time::timeout` in `fetch_bytes`;
  user-agent policy = explicit-only (caller-supplied wins, `None` sends no header; `DEFAULT_USER_AGENT = "v2rayN"` available, never injected);
  proxy = explicit `http(s)://` only, environment proxy never read (`no_proxy` base);
  trust = `System` (OS/native) vs `BundledPem(Vec<u8>)` (exclusive, `tls_built_in_root_certs(false)`), mapping `RootCertProvider` strings with system fallback — same contract as the pre-existing `subscriptions::tls` / `updater::tls`.
- Test seam: `SharedHttpClient::new` (counts via `construction_count()`), `SharedHttpClient::shared` (cached per equal `HttpPolicy`, clones share one `Arc<reqwest::Client>` via `same_inner()`), `reset_construction_count_for_tests()` / `clear_cache_for_tests()`.
- Async fetch API (FLD-CFG-087 infra half): `fetch_bytes` / `fetch_text` — manual redirect follow (auth headers dropped on origin change, `max_redirects` bound), `max_bytes` body cap, `domain::CancellationToken` cooperative cancel, `HttpError::{Timeout, Cancelled, TooLarge, InvalidUri, Header, Redirect, Http}` (credential-free).
- Consumers switched to the single seam:
  `subscriptions::download::Downloader` (stores `SharedHttpClient`, `shared()` per policy),
  `updater::fetch::CoreReleaseApi` + `updater::download::FileDownloader` (same),
  `application::webdav::WebDavClient` (same),
  `application::routing::fetch_rules_text` now delegates to `platform::http::fetch_text` via new cancellable `fetch_rules_text_cancel` (external routing-template download path).
