## 5. 未覆盖项 / 未决

- `V2rayFmt`/`SingboxFmt` 只做结构识别与原文保留（`extra["RawConfig"]`），未把 outbound 反解为
  协议 Profile；后续由 config_codegen（T07/T08）消费原文。与上游一致（上游亦只产出 Custom/Outbound）。
- `ClashFmt` 仅检测完整 clash 配置（上游行为相同），未解析 `proxies` 列表为节点。
- SIP008 的 `plugin` 字段未使用（上游 `ResolveSip008` 同样忽略）。
- `GetLeafCertSha256Thumbprint` 简化为“首个 PEM 证书”，未按 BasicConstraints 跳过 CA 证书。
- 下载器仅支持 HTTP/HTTPS 显式代理；未启用 reqwest `socks` feature（本地缓存无 `tokio-socks`）。
- 上游 `RegexMatchTimeout`（2s）由 Rust `regex` 线性引擎 + 长度/尺寸上限替代；lookahead 等不受支持
  的模式 fail-open（与上游“非法模式 fail-open”一致）。
- URL 解析依赖 `url` crate（WHATWG）；少数 .NET `Uri` 特有边角（如 legacy socks 无 `@`）已在
  `src/fmt/socks.rs` 显式改为“仅有可用端口才走新式”，见 decisions。
- 取消只在逐条安全点检查，不中断单次 base64 解码内部。
