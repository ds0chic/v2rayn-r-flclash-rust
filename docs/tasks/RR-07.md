输入、输出、错误、取消、权限、持久化及生效语义：
- 输入：一份完整 Custom 配置 JSON（inline `customConfigText` 或 `<data>/config/*.json` 文件），Xray 或 sing-box。
- 输出：`RuntimePlan.ports` 含配置内每个 socks/http/mixed inbound 的真实端口（按 UDP 加 UDP claim），以及 API/telemetry 端口的非独占 claim；`applied_session.proxy_port` = net-host 报告的真实监听端口；`local_proxy_url()` = `<scheme>://127.0.0.1:<port>`，scheme 取配置内首个代理 inbound 的协议（socks→`socks5`，http/mixed→`http`）；`monitor_session.state_port`（Xray metrics.listen）/`state_port2`（sing-box `experimental.clash_api`）= 配置内真实 API 端口。
- 错误：配置无 socks/http inbound、或 JSON 非法/无法解析 → 结构化 `E_INVALID_PLAN` / `error.custom_endpoint_parse_failed`，计划构建失败、不启动、不假装 ready。
- 取消/权限：无新增；不启动内核（本卡只给定 plan 与事实），测试用真实 xray 直接 spawn。
- 持久化：不改变 Custom 配置内容与存储（仍 inline/文件直通）。
- 生效：普通节点仍走 `opts.local_port` 与 settings inbound；Custom 走真实解析值。
